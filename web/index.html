✦ Penlight Dream Box Bestdori Profile Exporter

GARUPA → BESTDORI

导出玩家资料

按步骤从 Garupa 获取玩家资料，生成可以直接导入 Bestdori Profile Manager 的文件。

01 · SET UP CAPTURE

安装抓取配置

↗

选择正在使用的 iOS 代理客户端，一键远程安装对应配置，不需要下载或保存脚本。

SR Shadowrocket 远程安装 Module ↗ S Surge 远程安装 Module ↗ ST Stash 远程安装 Override ↗ L Loon 远程导入 Plugin ↗ QX Quantumult X 添加远程 Rewrite ↗

安装后开启 MITM 并信任证书，再打开 Garupa 的个人资料页。

02 · CAPTURE CREDENTIALS

粘贴客户端通知

⌘

在游戏触发请求后，点击代理客户端通知复制 JSON，再粘贴到这里自动填入 UID 和 UUID。

03 · EXPORT PROFILE

确认并导出资料

仅本次请求
Garupa 客户端平台
选择要模拟的 Garupa 客户端平台
服务器访问密钥 可选

04

导入 Bestdori Profile Manager

资料下载完成后，在 Profile Manager 选择「导入资料」即可。

打开 Profile Manager ↗
⌁ 网页不会保存 UID、UUID；它们只用于当前导出请求。加密密钥始终保留在服务器端。
